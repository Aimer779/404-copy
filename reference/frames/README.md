# 视频帧索引

源视频：`再花里胡哨一点_在网页里使用ASCII动画(720P).mp4`（1280 × 720、约 383.64 秒、约 30 fps）。

- `overview/`：全片每 5 秒一帧，共 77 张；`overview-contact-sheet.jpg` 是其缩略总览，按从左到右、从上到下的顺序排列。
- `404-demo-0-24s/`：开场的 404 成品效果，每 0.2 秒一帧，共 120 张。`frame-001.jpg` 对应 00:00.0，时间 = `(序号 - 1) / 5` 秒。
- `404-demo-contact-sheet.jpg`：开场效果的逐秒缩略总览，按从左到右、从上到下的顺序排列。
- `final-effect-356-384s/`：后段 ASCII 成品演示，每 0.5 秒一帧，共 55 张。`frame-001.jpg` 对应 05:56.0，时间 = `356 + (序号 - 1) / 2` 秒。
- `final-effect-contact-sheet.jpg`：后段演示的逐秒缩略总览。
- `scenes/`：以 `scene > 0.22` 阈值自动检出的 114 张变化帧；动态故障效果会触发较多误报，只作快速定位参考。原始时间戳见 `scene-timestamps.log`。

复刻时优先以 `404-demo-0-24s/` 比对开场的轮换节奏、色彩与故障条；ASCII 画面本体则用 `final-effect-356-384s/` 检查字符密度、明暗和入场过程。
